### Matrix Library (C++)
A lightweight matrix library built from scratch in C++ using templates and a clean namespace design. Developed alongside 
a university linear algebra course to reinforce mathematical concepts through code.

- Generic type support via templates (`int`, `float`, `double`)
- Arithmetic operators: `+`, `-`, `*`, scalar multiplication, compound assignment
- Transpose, row echelon form (with partial pivoting)
- Determinant and matrix inverse (Gauss-Jordan elimination)
- Matrix power (positive, zero, and negative exponents)
- Utility checks: `isSquare`, `isSymmetric`, `isIdentity`, `isSingular`
- Rank, trace, bounds-checked element access via `at()`
- Full exception handling with descriptive error messages

### Heart Disease Predictor (C++)
A logistic regression classifier built from scratch in C++ to predict whether a patient has heart disease based on 13 clinical features.  
Trained on the UCI Heart Disease Dataset (1025 patients) with no ML libraries — just math and code.  
Includes:
- Custom CSV parser  
- Feature normalization (min-max scaling)  
- Batch gradient descent with binary cross-entropy loss  
- Evaluation metrics: accuracy, precision, recall, F1 score  

Results: **85.6% accuracy**, **90.5% recall**  
Built on top of my custom matrix library.
